# Phase 1 Progress

Working log for Phase 1. The long-term plan and the decision log are in `plan/PLAN.md`; this file tracks the Phase 1 work item by item, with results as they come in.

**Phase 1 goal (set by the owner, 2026-11-24):** one complete, small end-to-end iteration of the study:

1. Build, normalize and freeze the road graph.
2. Build an evaluation question set: 50 questions per type (L1-L5), 250 in total.
3. Try Graph RAG (LightRAG) and one easy-to-implement method.
4. Compare and analyse the results.
5. Write the Phase 1 report.

**Mandate:** the owner accepted the graph work and asked for all of Phase 1 to be completed without further approval steps (2026-11-24). The experiment protocol is still written down first (`experiments/EXP-001-phase1-pilot/protocol.md`) so the design is fixed before any run.

**Change of priority (owner, 2026-11-25):** the graph is the most important Phase 1 output, because a large, verified reference graph is one of the thesis contributions and the processing rules must scale to larger areas without hidden bugs. Graph v2 is built from a written processing design (`docs/graph_v2_design.md`) and a review of every regular street and every junction. Everything run on graph `hcmc_district1_v2_p1` / benchmark v0.2 is a pipeline trial; Phase 1 results are produced on graph v2.
