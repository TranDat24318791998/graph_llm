## 1. Question

What this experiment is meant to find out, in one or two sentences.

## 2. Hypothesis

The prediction being tested and the result that would reject it.

## 3. Design

- **Independent variables:** what is varied, and the levels.
- **Controlled variables:** what is held constant (LLM, answering prompt, output format, context budget, seed).
- **Data:** benchmark version, graph version, number of questions per type.
- **Models:** exact model names and serving parameters.

## 4. Implementation

- Config files used.
- Command that launches the runs.
- Code version (git commit) at launch.

## 5. Evaluation

- Metrics, per question type.
- Statistical tests and significance level.
- How failures are handled (unparseable answers, timeouts).

## 6. Expected cost

Number of runs, estimated GPU time and tokens.

## 7. Deviations

Changes made after approval, each with a date and a reason. Empty if none.
